Setup Required for Preview Deployments

1Shopify Product

  • Create "Custom Token" product in Shopify admin
  • Two variants: "We Design It" and "You Design It"
  • Set pricing per variant
  • Add product description for landing page

2Environment Variables

  • Add to Oxygen environment settings:
  • OPENAI_API_KEY — production key
  • OPENAI_API_KEY_PREVIEW — limited key
  • AI_IMAGE_PROVIDER=openai
  • AI_MAX_GENERATIONS_PER_SESSION=7
  • AI_MAX_GENERATIONS_PER_DAY=100

3Klaviyo Flow

  • Create "Custom Token Order" event in Klaviyo
  • Build email template with design brief fields
  • Set admin as recipient
  • Include image URL links in template
Preview vs Production Environment Differences
# Preview environment (feature branches)
OPENAI_API_KEY="sk-preview-..."       # Lower rate limits
AI_MAX_GENERATIONS_PER_DAY="20"       # Tight cap for demos
KLAVIYO_PRIVATE_API_KEY="..."         # Same key (or test key)

# Production environment (main branch)
OPENAI_API_KEY="sk-prod-..."          # Full rate limits
AI_MAX_GENERATIONS_PER_DAY="500"      # Higher cap
KLAVIYO_PRIVATE_API_KEY="..."         # Production key
Tip: Oxygen lets you set environment variables per deployment environment in the Shopify admin under Hydrogen > Your Store > Settings > Environments. Preview branches automatically use the preview environment variables. You can also set them via shopify hydrogen env push.
Go-Live Checklist

Before Demo (Preview)

☐ Custom Token product created in Shopify with both variants
☐ OpenAI preview API key set in Oxygen preview env
☐ All env vars configured for preview
☐ Klaviyo flow created and tested
☐ Test full "We Design" flow end-to-end
☐ Test full "You Design" flow with AI generation
☐ Verify cart line items show in Shopify order
☐ Verify Klaviyo admin email fires correctly
☐ Test on mobile
☐ Share preview URL for stakeholder review

Before Production (Merge to main)

☐ All demo feedback addressed
☐ Production OpenAI key set in Oxygen prod env
☐ Rate limits tuned for expected traffic
☐ Hero CTA and product page CTAs enabled
☐ Error states tested (API failure, rate limit hit)
☐ Analytics events tracked (PostHog)
☐ CSP headers updated for OpenAI API domain
☐ Merge feature branch to main
