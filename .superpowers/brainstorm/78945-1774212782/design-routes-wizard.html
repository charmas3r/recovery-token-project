Section 2: Route Structure & Wizard Flows

File layout, step progression, and session state management

"We Design It" Flow — 5 Steps
1
Occasion
Route: we-design.occasion.tsx
Multiple choice: Sobriety milestone, Memorial, Custom gift, Organization/Group
Session writes: customToken.occasion
2
Design Description
Route: we-design.description.tsx
Free text description + up to 5 inspiration image uploads
Session writes: customToken.description, customToken.inspirationImageUrls[]
3
Material
Route: we-design.material.tsx
Brass vs Color options — maps to Shopify product variant
Session writes: customToken.material, customToken.variantId
4
Engraving Details
Route: we-design.engraving.tsx
Name, date, custom text — reuses existing EngravingForm patterns
Session writes: customToken.engraving{name,years,cleanDate,note}
5
Review & Add to Cart
Route: we-design.review.tsx
Summary of all selections. Email confirmation note. CartForm submission with line item properties.
Action: adds to cart, clears session, triggers Klaviyo event
"You Design It" Flow — 5 Steps
1
Describe Your Design
Route: you-design.describe.tsx
Guided prompt: theme, symbols, text, style. Optional reference image upload.
Session writes: customToken.designPrompt, customToken.referenceImageUrls[]
2
AI Preview — Initial Options
Route: you-design.preview.tsx
System amends prompt → generates 4 token design previews. Customer picks favorite.
Action: calls AI adapter, stores images. Session writes: customToken.selectedPreviewUrl
3
Refine Design
Route: you-design.refine.tsx
Shows selected design. Customer can type refinements ("make eagle larger"). Re-generates. Max 3 refinement rounds.
Action: calls AI adapter with refinement. Session writes: customToken.finalDesignUrl
4
Material
Route: you-design.material.tsx
Same material selection as "We Design" — shared component
Session writes: customToken.material, customToken.variantId
5
Review & Add to Cart
Route: you-design.review.tsx
Shows final design preview, material, summary. CartForm submission with design image URL in line item properties.
Action: adds to cart, uploads final image to Shopify files, clears session, triggers Klaviyo
