Key Architecture Decisions

  • Session-based wizard state — Each step's action writes to the Hydrogen session. Steps read from session in their loader. Survives page refresh.
  • Layout route for shared UI — ($locale).custom-token.tsx is a layout route providing progress bar, back navigation, and the session context. Child routes render each step.
  • AI adapter in app/lib/ai/ — Interface defined once, implementations per provider. System prompt template lives alongside. Swap providers by changing an env var.
  • Line item properties for order data — Design path, description, material choice, image URLs, and engraving details all stored as cart line attributes. Visible in Shopify admin order view.
  • Klaviyo event on order creation — Shopify webhook triggers Klaviyo flow that emails admin a formatted design brief with all customer selections and image links.
